# EXCEL 規則政策整理（Processor 實作版）

來源檔案：`docs/policy/excel-policy.pdf`（由 `EXCEL規則.pdf` 複製）

> 本文件為可實作規格草案，將原 PDF 內容結構化，供 Processor 模組落地。

## 1. 客戶行業別取得（步驟一）

- 行業別是 AI 判定扣抵與否的重要條件之一。
- 行業別來源有兩案：
- 方案 A：由事務所提供行業代碼。
- 方案 B：由公開資訊網站依統編查詢公司行業別公告資料。
- 目前狀態：待決議（PDF 原文即標示待討論）。

## 2. 發票類型分類（步驟二）

以格式代號分類，規則如下：

1. 進銷項 Excel（表一）工作表 1，欄位 C = 35：分類為 銷項發票(35)
2. 進銷項 Excel（表一）工作表 1，欄位 C = 25：分類為 進項發票(25)
3. 折讓單 Excel（表二）工作表 1，欄位 B = 33：分類為 銷貨折讓(33)
4. 折讓單 Excel（表二）工作表 1，欄位 B = 23：分類為 進貨折讓(23)

## 3. 可否扣抵判定（步驟三）

### 3.1 判定範圍

- 只判定 進項發票(25)。
- 其他三類（35/33/23）不做扣抵判定。

### 3.2 判定單位

- 以同一張發票號碼為群組。
- 依第 2 工作表欄位 D（品名）與品項金額進行判定。

### 3.3 品項判定規則

1. 同張發票僅 1 個品名：
- 直接以該唯一品名做 AI 可否扣抵判定。

2. 同張發票有多個品名，且「沒有任何」品項金額 > 6,000：
- 只判定該張發票金額最高品項。
- 其他品項沿用「最高金額品項」判定結果。

3. 同張發票有多個品名，且有「兩個以上」品項金額 > 6,000：
- 各個 > 6,000 品項需獨立判定。
- 其餘 <= 6,000 品項，沿用「最高金額品項」判定結果。

## 4. 會計科目判定（步驟四，限進項發票(25)）

### 4.1 借方判定

- 依會計項目表（PDF 提及表五）由 AI 選擇借方科目。
- 借方類別分為：成本類 / 費用類。

### 4.2 貸方判定（由金額門檻）

若借方為成本類：

1. 金額 > 10,000：貸方 2130（應付帳款）
2. 1,000 < 金額 < 10,000：貸方 1110（銀行存款）
3. 金額 < 1,000：貸方 1105（現金）

若借方為費用類：

1. 1,000 < 金額 < 10,000：貸方 1110（銀行存款）
2. 金額 < 1,000：貸方 1105（現金）

### 4.3 取值範圍（同發票、同扣抵別）

- 僅對「同一發票、同一可否扣抵結果」中金額最大的品項判定借貸方。
- 非最大品項標記為「不判定」。

## 5. 歸檔、摘要、分攤稅額（步驟五）

### 5.1 群組與彙總

- 每張發票先分成兩組：可扣抵 / 不可扣抵。
- 同組金額加總後，集中到該組的主要品項（最大金額品項）。
- 同組其他品項金額可歸零（範例顯示為 0）。

### 5.2 稅額分攤

- 針對可扣抵組計算稅額：
- 稅額 = 銷售額 * 0.05 / 1.05（四捨五入）。
- 營業稅差額歸入不可扣抵組。

### 5.3 品名清理

- AI 需移除品名贅詞（範例顯示如 `★螢幕★` 之清理情境）。

## 6. 對 Processor 的直接實作需求（建議）

1. 新增「發票類型分類器」
- 讀取來源檔型（表一/表二）與代號欄位（C 或 B）。
- 產出分類碼：35/25/33/23。

2. 新增「進項發票(25)品項選取器」
- 以發票號碼分組，依 6,000 門檻與最大金額規則選出 AI 判定目標列。

3. 新增「判定結果回填器」
- 將 AI 判定結果回填至同發票其餘列（依據最高金額）。

4. 新增「借貸方決策器」
- 先決定借方科目與類別（成本/費用）。
- 再套用貸方門檻規則（2130/1110/1105）。

5. 新增「分組彙總與稅額分攤器」
- 同發票按可扣抵別分組。
- 群組金額與稅額計算，差額進不可扣抵。

6. 新增欄位規則與驗證
- 對應 PDF 涉及欄位（格式代號、品名、金額、發票號碼、稅額）建立 schema 與錯誤訊息。

2. 借方「費用類」在金額 >= 10,000 的貸方規則未明確記載，是否比照成本類（2130）？
3. 「最高金額品項」是否以絕對值比較（含負數折扣），還是僅正金額比較？
4. 稅額四捨五入位數：到整數元還是到小數第幾位？
5. 品名贅詞移除規則白名單/黑名單（例如符號、促銷字樣）是否需固定字典？
