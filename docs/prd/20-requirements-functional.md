# Functional Requirements

## Invoice Downloader

FR-001

System shall import customer list Excel files.

FR-002

System shall read Tax ID from customer list.

FR-003

System shall read Company Name from customer list.

FR-004

System shall read Date Range from customer list.

FR-005

System shall allow MOF account configuration.

FR-006

System shall allow API credential configuration.

FR-007

System shall download customer invoices.

FR-008

System shall support batch invoice downloading.

FR-009

System shall export downloaded invoices to Folder A.

## Configuration

FR-010

System shall support INI configuration files.

FR-011

System shall support output naming rules.

FR-012

System shall validate naming placeholders.
