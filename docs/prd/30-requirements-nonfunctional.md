# Non-Functional Requirements

## Platform and Compatibility

- **NFR-001**: Runtime applications shall target Windows desktop (`net8.0-windows`) and remain executable on supported Windows environments.
- **NFR-002**: Core library shall remain buildable on `.NET 8` and test suite shall remain runnable on `.NET 9` test target.

## Performance and Throughput

- **NFR-003**: The decision pipeline shall pass synthetic scale tests at 30,000 records and 150 customers.
  - Validation: `LocalizationAndQualityGateTests` scale test cases.
- **NFR-004**: Batch operations shall provide progress/summary counters for operator observability.
  - Validation: processor progress callback + UI status rendering behavior.

## Security and Privacy

- **NFR-005**: AI inference logic shall execute locally without outbound calls to external AI services.
  - Validation: code-path quality gate test.
- **NFR-006**: MOF password persistence shall use Windows DPAPI encryption for stored INI values.
  - Validation: `MofPasswordProtectorTests`.
- **NFR-007**: Governance-sensitive training execution shall fail fast on invalid/unapproved policy metadata.
  - Validation: `TrainingWorkflowServiceTests` policy-approval failure cases.

## Reliability and Error Handling

- **NFR-008**: Downloader batch execution shall continue after individual-customer failure and report final mixed outcomes.
  - Validation: `OfficialBatchInvoiceDownloaderIntegrationTests` + unit tests.
- **NFR-009**: Output file naming collisions shall be resolved deterministically with suffix increment.
  - Validation: `OutputFileNameHelperTests`.
- **NFR-010**: Invalid schemas/inputs shall produce explicit exceptions or user-visible error messages, not silent fallback success.
  - Validation: importer/config/reader test suites.

## Data Integrity and Determinism

- **NFR-011**: Folder B/C exports shall preserve deterministic ordering by date/invoice number inside each output group.
  - Validation: exporter unit tests and deterministic sort logic.
- **NFR-012**: Knowledge and training governance preprocessing shall be deterministic for duplicate/conflict tie-break rules.
  - Validation: governance preprocessor and bootstrap engine test suites.
- **NFR-013**: Train/validation/test split shall enforce cohort leakage guard for same company-month cohort.
  - Validation: `TrainingWorkflowServiceTests` split-policy cases.

## Localization and UX Consistency

- **NFR-014**: User-facing module UI text and business-facing result labels shall remain Traditional Chinese.
  - Validation: UI/XAML content + localization quality-gate tests.
- **NFR-015**: AI decision reason strings generated by the local analyzer shall remain Traditional Chinese.
  - Validation: `LocalHeuristicLlmAnalyzer` tests.

## Operability and Auditability

- **NFR-016**: Training workflow shall emit auditable artifact set under `build/training/` (staged/published model, evaluation report, publish metadata, quality-gate reports).
  - Validation: `TrainingWorkflowServiceTests` and reporter tests.
